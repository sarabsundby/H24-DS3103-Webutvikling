API Documentation

Everything you need to interact with the best API to ever exist.

Base

Base url: http://localhost:5021/api/

The base url doesn't contain any data itself, so you have to combine it with one of the available resources. All requests are GET-requests which uses HTTP and return JSON. 


{
  "merch": "http://localhost:5021/api/merch",
  "staff": "http://localhost:5021/api/staff"
}

Currently available resources:

  • Merch: used to get all the merch.
  • Staff: used to get all the staff.

Merch schema

Key Type Description
id int The id of the merch.
name string The name of the merch.
type string The type of merch.
price int How much the merch costs.
size string What sizes the merch has available.
amount int The amount of merch in stock.
image string An image of the merch.

Staff schema

Key Type Description
id int The id of a staff member.
firstname string The staff member's firstname.
lastname string The staff member's lastname.
birthdate string The staff member's birthday.
email string The company email to the staff member.
phone int The staff member's phonenumber.
role string What role/title the staff member has.
image string An image of the staff member.
